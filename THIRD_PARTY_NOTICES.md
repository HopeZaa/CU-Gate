The local map and OSM gate-node extract contain © OpenStreetMap contributors data, available under the [Open Database License 1.0](https://www.openstreetmap.org/copyright). The campus GeoJSON is a derivative database. Attribution is always visible on the map and in the data-quality view. The original bounded data endpoint, retrieval date and relevant node versions are recorded in `public/research/osm-barriers.json` and `src/data/gates.json`. The limited map extract is not an official campus boundary or a routing network.

No raster tiles are downloaded or prefetched. The application makes no Overpass or map-research requests at runtime. Place geocoding is optional and only starts after an explicit submitted search. It serves a static, bounded OSM extract with MapLibre GL JS. This avoids a mandatory third-party tile service, key or paid API. Areas beyond the local extract have limited context. A map update requires a reviewed replacement extract and static redeployment.

If adding the public OSM raster tile service later, follow its [tile usage policy](https://operations.osmfoundation.org/policies/tiles/): use the documented HTTPS endpoint, preserve browser Referer and cache headers, show attribution, and never prefetch or offer offline tile downloads. Public servers have no service guarantee. Local GeoJSON is OSM database data, not cached OSM Carto tiles.

Google Maps directions are external URLs, as documented in the [Maps URLs guide](https://developers.google.com/maps/documentation/urls/get-started). The app supplies the destination and selected travel mode. If the user explicitly selects a public landmark, place-search result or manually entered coordinates, that selected starting coordinate is included as `origin`. Device-location coordinates are not added to the URL as `origin`. The user decides whether to open Google Maps. Google may use its own account/device permissions and may not support every routing mode or private campus path. A suggested route does not establish that a gate can be used. The app itself computes only great-circle distances, never a walking or driving route.

Geolocation requires a secure context (HTTPS or localhost), browser permission and working location services. The user's coordinates stay in React memory. They are not logged, stored or uploaded. Watches stop on page hiding, explicit Stop, errors and unmount. Language, light/dark theme and the collapsed legend preference are saved in localStorage. Compass readings also stay in memory and listeners are removed with the GPS watch. No analytics or authentication is included.

MapLibre GL JS (BSD-3-Clause), React (MIT), Vite (MIT), TypeScript (Apache-2.0), Tailwind CSS (MIT), Lucide (ISC), Zod (MIT), ESLint (MIT), and Vitest (MIT) retain their package licenses in their distributions. Consult the installed packages for complete license text. University documents are cited as research evidence; full documents are not redistributed in the application. English gate names without an official-map source are marked as editorial translations.

The local place-search index contains centres of 698 named OSM ways from the same bounded extract and is covered by ODbL with the map data. These are reference locations rather than surveyed gate entrances. Optional online search uses [Photon](https://github.com/komoot/photon), an Apache-2.0 geocoder using OpenStreetMap data. Its public demo is intended for moderate use without availability guarantees; explicit submissions, a request interval and memory caching limit traffic. Replace/disable the provider through `location-search.json` for other deployment needs. Submitted search text and ordinary network metadata go to the configured provider; device GPS and heading never do. Online results and local results carry OSM/Photon attribution.
